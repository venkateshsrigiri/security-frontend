#  Smart Security Scanner – Frontend

This is the frontend of the Smart Security Scanner, a web-based application that allows users to scan files and URLs for potential security risks.

##  Live Demo
 https://security-frontend-jejz.vercel.app/

---

##  Features

- Upload files (PDF, documents) for scanning
- Submit URLs for security analysis
- Displays risk score and detailed scan report
- Clean and user-friendly interface
- Real-time scan results

---

## Tech Stack

- React
- Axios (API calls)
- HTML, CSS, JavaScript

---

## How It Works

1. User uploads a file or enters a URL
2. Frontend sends request to backend APIs
3. Backend processes the scan
4. Results (risk score + findings) are displayed to the user
